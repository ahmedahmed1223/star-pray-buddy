## المرحلة 5: نظام تخصيص الثيمات لكل طفل (جديد)

### 5.1 ثيمات ألوان مخصصة لكل طفل
- إضافة `childTheme` property في `Child` interface بـ `store.ts`
- 6 ثيمات لونية جاهزة:
  - **ذهبي** (الافتراضي): الألوان الحالية
  - **محيط أزرق**: تدرجات زرقاء هادئة
  - **حديقة خضراء**: تدرجات خضراء طبيعية
  - **غروب بنفسجي**: تدرجات بنفسجية دافئة
  - **فضاء كوني**: ألوان داكنة مع نيون
  - **وردي ناعم**: تدرجات وردية للبنات
- كل ثيم يغير: لون primary، ألوان أزرار الصلاة، لون الـ glow، خلفية الصفحة

### 5.2 اختيار الثيم من صفحة الطفل
- إضافة زر "تخصيص" (🎨) في header صفحة `KidTracker.tsx`
- عرض dialog يحتوي على معاينة مباشرة لكل ثيم
- حفظ الاختيار في `store.ts` مرتبط بكل طفل

### 5.3 تطبيق الثيم ديناميكياً
- عند فتح صفحة طفل، تُطبق CSS variables خاصة به عبر `style` attribute
- الثيم يؤثر على: `PrayerButton`, `LanternProgress`, `WeeklyCalendar`, `BottomNav`, headers

| الملف | التغيير |
|-------|---------|
| `src/lib/store.ts` | إضافة `ChildTheme` + `CHILD_THEMES` + دوال |
| `src/pages/KidTracker.tsx` | زر تخصيص + تطبيق الثيم |
| `src/components/ThemePickerDialog.tsx` | **جديد** — dialog اختيار الثيم |
| `src/components/PrayerButton.tsx` | دعم ألوان الثيم المخصص |
