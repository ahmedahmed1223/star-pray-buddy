## المرحلة 1: نظام الأهداف اليومية والعادات (أولوية عالية)

### 1.1 أهداف يومية مخصصة لكل طفل
- إضافة واجهة "الهدف اليومي" في `KidTracker.tsx` تعرض تحدي اليوم (مثلاً: "صلِّ الفجر في وقته")
- تخزين الأهداف في `store.ts` مع نظام أهداف تلقائية تتغير يومياً
- مكافأة نجوم إضافية عند تحقيق الهدف اليومي

### 1.2 متتبع عادات القرآن
- إضافة عداد صفحات/أجزاء القرآن المقروءة يومياً في `KidTracker.tsx`
- شريط تقدم لختم القرآن (30 جزء) مع احتفال عند الإنجاز
- إحصائيات القراءة في صفحة الإنجازات

| الملف | التغيير |
|-------|---------|
| `src/lib/store.ts` | إضافة `DailyGoal`, `QuranLog` interfaces + دوال CRUD |
| `src/pages/KidTracker.tsx` | عرض الهدف اليومي + عداد القرآن |
| `src/pages/AchievementsScreen.tsx` | إحصائيات القرآن |

## المرحلة 2: نظام المتجر والمكافآت المتقدم (أولوية عالية)

### 2.1 متجر المكافآت
- صفحة جديدة `RewardShop.tsx` يستبدل فيها الطفل نجومه بمكافآت
- الوالد يضيف المكافآت من لوحة التحكم (مع الصور والأسعار بالنجوم)
- سجل عمليات الاستبدال مع إشعار للوالد

### 2.2 نظام الكوبونات
- الوالد ينشئ كوبونات (مثل: "ساعة ألعاب إضافية") بعدد نجوم محدد
- الطفل "يشتري" الكوبون ويعرضه للوالد لتفعيله

| الملف | التغيير |
|-------|---------|
| `src/pages/RewardShop.tsx` | جديد — واجهة متجر المكافآت |
| `src/lib/store.ts` | إضافة `ShopItem`, `RedemptionLog` + دوال |
| `src/pages/ParentDashboard.tsx` | إدارة المتجر من تبويب المكافآت |
| `src/App.tsx` | إضافة route جديد `/shop/:childId` |
| `src/components/BottomNav.tsx` | إضافة تاب المتجر |

## المرحلة 3: تحسينات تجربة المستخدم البصرية (أولوية عالية)

### 3.1 شخصية مساعدة متحركة (Mascot)
- إضافة شخصية SVG متحركة (نجمة أو فانوس) تظهر في `KidTracker` و `KidSelection`
- الشخصية تتفاعل مع الأحداث: تفرح عند الصلاة، تحزن عند التأخر، تنام ليلاً
- فقاعة حوار تعرض نصائح ورسائل تحفيزية عشوائية

### 3.2 خريطة المغامرة (Adventure Map)
- مكون `AdventureMap.tsx` يعرض مسار بصري (خريطة طريق) لتقدم الطفل
- كل 10 نجوم = محطة جديدة على الخريطة مع رسومات مختلفة (مسجد، حديقة، مدرسة)
- تأثيرات حركية عند فتح محطة جديدة

### 3.3 تحسين صفحة اختيار الأطفال
- إضافة إحصائيات سريعة أسفل كل بطاقة طفل (نسبة اليوم، الشعلة)
- تأثير "glow" على بطاقة الطفل الذي أتم صلواته اليوم
- ترتيب الأطفال حسب النشاط (الأنشط أولاً)

| الملف | التغيير |
|-------|---------|
| `src/components/Mascot.tsx` | جديد — شخصية SVG متحركة |
| `src/components/AdventureMap.tsx` | جديد — خريطة تقدم بصرية |
| `src/pages/KidSelection.tsx` | إحصائيات سريعة + ترتيب + glow |
| `src/pages/KidTracker.tsx` | دمج الشخصية المساعدة |

## المرحلة 4: ميزات اجتماعية وعائلية (أولوية متوسطة)

### 4.1 رسائل تشجيع من الوالدين
- الوالد يكتب رسالة تشجيعية خاصة تظهر للطفل عند فتح التطبيق
- إمكانية جدولة الرسائل (رسالة صباحية، مسائية)
- قالب رسائل جاهزة يختار منها الوالد

### 4.2 تحدي الأسرة الأسبوعي
- تحدي مشترك لكل الأطفال (مثل: "صلوا الفجر جماعة 5 أيام")
- شريط تقدم مشترك يظهر لجميع الأطفال
- مكافأة جماعية عند تحقيق التحدي

### 4.3 مشاركة الإنجازات
- زر مشاركة في `AchievementsScreen` ينشئ صورة إنجاز قابلة للمشاركة
- تصميم بطاقة مشاركة جميلة مع اسم الطفل وإنجازاته
- دعم Web Share API للمشاركة المباشرة

| الملف | التغيير |
|-------|---------|
| `src/lib/store.ts` | إضافة `ParentMessage`, `FamilyChallenge` |
| `src/pages/ParentDashboard.tsx` | واجهة كتابة الرسائل + إدارة تحدي الأسرة |
| `src/pages/KidTracker.tsx` | عرض رسالة الوالد + تحدي الأسرة |
| `src/pages/AchievementsScreen.tsx` | بطاقة مشاركة + Web Share API |

## المرحلة 5: تحسينات تقنية وأداء (أولوية متوسطة)

### 5.1 وضع عدم الاتصال المحسّن
- إضافة Service Worker caching strategy محسّنة
- مؤشر بصري لحالة الاتصال (أونلاين/أوفلاين)
- مزامنة البيانات عند عودة الاتصال

### 5.2 إحصائيات متقدمة للوالدين
- رسم بياني حراري (Heatmap) يعرض أيام الصلاة على مدار السنة
- تقرير شهري تلقائي يُرسل كإشعار للوالد
- مقارنة أداء الشهر الحالي بالشهر السابق

### 5.3 تخصيص المظهر
- الطفل يختار لون الثيم الخاص به (أزرق، أخضر، بنفسجي)
- خلفيات متعددة قابلة للاختيار (مسجد، فضاء، حديقة)
- إمكانية تغيير شكل أزرار الصلاة (دائري، مربع، بطاقة)

| الملف | التغيير |
|-------|---------|
| `src/components/Heatmap.tsx` | جديد — رسم بياني حراري |
| `src/pages/ParentDashboard.tsx` | Heatmap + تقرير شهري |
| `src/lib/store.ts` | إضافة `ChildTheme` + إعدادات المظهر |
| `src/pages/KidTracker.tsx` | تطبيق الثيم المخصص |
