

# تحديث خطة التطوير: إضافة بند تحسين تصميم الشهادات

## الوضع الحالي

الشهادة الحالية في `AchievementsScreen.tsx` عبارة عن SVG بسيط جداً: خلفية داكنة، إطار ذهبي منقط، ونصوص عادية فقط. لا تحتوي على أي رسومات زخرفية أو عناصر بصرية جذابة للأطفال.

## البند المقترح: تحسين تصميم الشهادات

### التحسينات:

1. **تصميم بصري غني بعناصر إسلامية وطفولية:**
   - إضافة رسومات SVG زخرفية: نجوم متلألئة، هلال، فوانيس، مسجد صغير في الأسفل
   - إطار مزخرف بنقوش إسلامية هندسية بدلاً من الإطار المنقط البسيط
   - خلفية متدرجة أجمل مع عناصر decorative (نجوم صغيرة متناثرة)

2. **ألوان مبهجة مناسبة للأطفال:**
   - تدرجات ذهبية وبنفسجية وزرقاء سماوية
   - ألوان مختلفة حسب مستوى الطفل (كل مستوى له ثيم لوني مميز)

3. **تخطيط أفضل:**
   - حجم أكبر (800x560 بدلاً من 600x400) ليكون واضحاً عند الطباعة
   - تنظيم المعلومات في أقسام واضحة مع فواصل زخرفية
   - عرض الأفاتار الخاص بالطفل في الشهادة
   - ختم أو وسام في الزاوية

4. **قوالب متعددة:**
   - قالب "إنجاز عام" (الحالي محسّن)
   - قالب "بطل الصلاة" (عند إكمال أسبوع كامل)
   - قالب "سلسلة ذهبية" (عند تحقيق streak معين)

5. **تصدير محسّن:**
   - تحويل SVG إلى PNG عبر Canvas API ليسهل مشاركتها
   - إمكانية مشاركة الشهادة مباشرة عبر واتساب كصورة

### الملفات المتأثرة:
