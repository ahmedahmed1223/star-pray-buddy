## 📖 نبذة عن التطبيق | About

**متابع الصلاة** هو تطبيق مصمم خصيصاً للأطفال لتشجيعهم على أداء الصلوات الخمس يومياً من خلال نظام مكافآت ممتع يتضمن نجوم، شارات، مستويات، وتأثيرات احتفالية. يدعم التطبيق عدة أطفال مع لوحة تحكم للوالدين محمية بـ PIN.

**Star Pray Buddy** is an app designed specifically for children to encourage them to perform the five daily prayers through a fun reward system featuring stars, badges, levels, and celebratory effects. The app supports multiple children with a PIN-protected parent dashboard.

## ✨ الميزات الرئيسية | Key Features

### 🕌 تتبع الصلوات | Prayer Tracking
- تسجيل الصلوات الخمس يومياً (الفجر، الظهر، العصر، المغرب، العشاء)
- تسجيل صلاة الجماعة لكل صلاة
- تأثيرات احتفالية عند إتمام كل صلاة وعند إكمال اليوم بالكامل
- إمكانية تعديل سجل الأيام السابقة

### ⭐ نظام المكافآت | Rewards System
- **5 مستويات** تصاعدية: مبتدئ ← متعلم ← مصلّي ← متميز ← بطل الصلاة
- **نجوم** تُجمع مع كل صلاة (نجمة إضافية لصلاة الجماعة)
- **شارات** إنجاز متنوعة (المحافظ، المبكّر، البطل، وغيرها)
- **سلسلة أيام متتالية (Streak)** مع عداد مرئي

### 💰 مكافآت مالية | Financial Rewards
- نظام مكافآت مالية قابل للتخصيص بالكامل
- تحديد مبلغ المكافأة لكل صلاة وكل جماعة
- اختيار العملة (ريال، دينار، جنيه، درهم...)
- تتبع رصيد كل طفل

### 📊 التقارير | Reports
- **تقويم أسبوعي** ملوّن يعرض الأداء اليومي
- **رسوم بيانية شهرية** باستخدام Recharts
- **فوانيس التقدم** — مؤشر بصري فريد مستوحى من رمضان

### 📋 أنشطة إضافية | Custom Activities
- إضافة أنشطة مخصصة (أذكار الصباح، قراءة القرآن، صدقة...)
- تحديد عدد النجوم لكل نشاط
- تتبع الأنشطة يومياً مع الصلوات

### 🎨 تجربة مستخدم مميزة | Unique UX
- **ثيم رمضاني** مع فوانيس وهلال ونجوم متحركة (SVG)
- **تأثيرات Confetti** عند إكمال جميع الصلوات
- **أصوات احتفالية** عند تسجيل الصلاة والحصول على شارة
- **Haptic Feedback** على الأجهزة المدعومة
- تصميم Mobile-first مع دعم Safe Areas

### 👨‍👩‍👧‍👦 إدارة الأطفال | Kids Management
- إضافة عدة أطفال مع صور أفاتار مميزة (10 خيارات)
- بطاقة لكل طفل تعرض المستوى والنجوم والـ Streak
- التنقل السلس بين الأطفال

### 🔒 وضع الوالدين | Parent Mode
- محمي بـ **رمز PIN** (4 أرقام)
- إدارة الأطفال (إضافة، تعديل، حذف)
- التحكم في إعدادات الجماعة والأنشطة والمكافآت المالية
- **تصدير واستيراد البيانات** (JSON)
- مشاركة التقرير الأسبوعي عبر **واتساب** أو كـ **شهادة SVG**
- إعداد **تذكيرات ذكية** لمواعيد الصلاة

### 📱 تطبيق أصلي | Native App
- **PWA** — يعمل كتطبيق من المتصفح مع إشعارات
- **Capacitor** — تحويل لتطبيق أصلي على iOS و Android
- دعم الـ **Status Bar** والـ **Splash Screen** والـ **Haptics**
- التوافق مع الأجهزة ذات النوتش (Safe Areas)

## 🚀 التشغيل المحلي | Local Development

### المتطلبات | Prerequisites
- [Node.js](https://nodejs.org/) v18+
- npm أو bun

### الخطوات | Steps

```bash
# 1. استنساخ المشروع | Clone the repo
git clone <YOUR_GIT_URL>
cd star-pray-buddy

# 2. تثبيت الحزم | Install dependencies
npm install

# 3. تشغيل خادم التطوير | Start dev server
npm run dev
```

سيعمل التطبيق على `http://localhost:5173`

## 📱 بناء تطبيق Native | Native App Build

### iOS (يحتاج Mac + Xcode)

```bash
# 1. بناء المشروع
npm run build

# 2. إضافة منصة iOS
npx cap add ios

# 3. مزامنة الملفات
npx cap sync ios

# 4. فتح المشروع في Xcode
npx cap open ios
```

### Android (يحتاج Android Studio)

```bash
# 1. بناء المشروع
npm run build

# 2. إضافة منصة Android
npx cap add android

# 3. مزامنة الملفات
npx cap sync android

# 4. فتح المشروع في Android Studio
npx cap open android
```

### تحديث بعد التغييرات

```bash
npm run build && npx cap sync
```
